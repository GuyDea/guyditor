## M4 Part 13 risk notes

- **R-006 — storage exhaustion:** category scans and operation formulas feed queue preflight with the required 10 GiB/5% headroom rule; failed preflight never calls the executor. Cleanup is structurally limited to regenerable paths, while archival reclaims source-media space only after the cold copy verifies.
- **R-009 — data loss:** backup sets enumerate load-bearing state and exclude derived caches, deduplicate by SHA-256, verify sampled/full objects, damage-flag bad runs, and support isolated restore tests. Archive uses copy–verify–manifest–delete, environment transfer excludes secrets, and migration requires both a verified backup and local pre-migration snapshot.
